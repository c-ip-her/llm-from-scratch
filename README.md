# LLM From Scratch

This repository documents my self-learning journey toward understanding and building Large Language Models from first principles.

Currently implemented:
- Tokenization pipeline
- Vector embeddings
- Self-attention mechanism
- Query-Key-Value computation
- Multi-head attention (work in progress)

## Goal
The long-term goal of this repository is to build a mini GPT-style transformer architecture from scratch in Python/PyTorch.

## Tech Stack
- Python
- PyTorch
- Jupyter Notebook

## Learning Focus
- Transformer internals
- Attention mechanisms
- LLM fundamentals
